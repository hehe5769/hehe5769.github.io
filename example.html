📅 予約管理システム (Reservation & Matching System)

顧客・業者・管理者の三層構造による業務効率化＆自動マッチング基盤

🔗 予約システムを開く
Spring Boot PostgreSQL Spring Security Leaflet / Map API 自動メール通知 レスポンシブWeb

本システムは、出張・修繕・家政等の各種生活サービスにおける予約から見積比較、業者マッチング、履践状況管理までをワンストップで完結できる独自開発プラットフォームです。
利用者はオンライン上で直感的に予約登録・キャンセルが行え、業者は地図上の案件位置や距離をもとに迅速に応答。管理者は専用ダッシュボードからすべての予約・見積状況をリアルタイムに可視化できます。

👤 顧客専用ポータル

直感的なフォームで24時間いつでも予約作成・変更・取消が可能。複数業者からの見積もりを自動比較し、最も費用対効果の高いプランを選択できます。

👷 業者向け案件マップ

地図検索機能により、現場の距離・地域・作業内容をビジュアルに把握。迅速な見積書作成と現場ステータス更新をスムーズに行えます。

📊 管理者ダッシュボード

全案件のリアルタイム状況（新規・確認中・確定・完了）を一目で把握。CSVデータエクスポートや顧客・業者のアカウント一元管理に対応。

🔒 堅牢なセキュリティ認証

Spring Securityを採用し、顧客・業者・管理者ごとの多層アクセス権限を徹底分離。安全で信頼性の高いデータ運用を実現しています。

https://fujimirv.jptungri.shop/
⚡ システム概要： 顧客・業者・管理者の三者をリアルタイムに結ぶマッチング＆予約管理プラットフォーム。見積もり比較から地図による現場案件検索、進捗ステータス管理までを一元化します。

👥 人事管理システム (Fujimino HR System)

従業員台帳・勤怠打刻・休暇申請承認を一元化する次世代HRソリューション

🔗 人事システムを開く
Webフロントエンド RESTful API 勤怠管理エンジン 多段階承認ワークフロー ロール権限管理 (RBAC) クラウドホスティング

企業や各種組織における人事業務のペーパーレス化と運用効率化を目的に開発された人事管理システム（HR SaaS）です。
従業員のプロファイル管理、日々の出退勤打刻や勤務時間集計、有給・病気等の休暇申請から上長・人事による承認フローまでを完全オンライン化し、人的ミスを最小限に抑え組織運営を強力に後押しします。

🗂️ 従業員台帳・プロファイル管理

氏名・所属部署・役職・連絡先・入社履歴などを一元管理。組織改編や人事異動にも柔軟に対応可能な拡張設計です。

⏱️ 勤怠打刻＆実働時間トラッキング

ワンクリック出退勤打刻に対応。残業時間や所定外労働時間を自動計算し、タイムシートの確認・集計の手間を大幅削減します。

📝 休暇申請＆ワークフロー承認

年次有給休暇や慶弔休暇をスマホ・PCから即時申請。直属上司や人事担当者への承認通知とステータス追跡がスムーズに行えます。

📈 労務データ出力＆分析

月次勤怠データや休暇取得状況のCSV出力に対応。給与計算ソフトウェアや外部会計サービスとの連携基盤としても機能します。

https://hr.fujimino.space/
💻 システム概要： クラウド上で直感的に操作できる管理コンソール。従業員ポータルとHR管理者コンソールを統合し、ペーパーレスなオフィスワークを支援します。

🏃 ふじみ野 総合スポーツクラブ (Fujimino Sports Club)

地域コミュニティの健康と活力をつなぐスポーツ情報＆オンライン予約ポータル

🔗 スポーツクラブを開く
HTML5 / CSS3 モダンJavaScript インタラクティブカレンダー オンライン参加受付 モバイル最適化

ふじみ野市地域で活動する総合スポーツクラブの公式ポータルサイトです。
バドミントン、ランニング、体幹トレーニング、ジュニア運動教室など多彩な種目プログラムの紹介をはじめ、開催スケジュールカレンダーの閲覧、練習会・体験レッスンへのオンライン参加予約を直感的に行えます。

🏸 多種目プログラム＆種目紹介

初心者から競技志向の方まで、目的やレベルに応じた各競技プログラムやコーチ紹介を視覚的に分かりやすく掲載しています。

📅 イベントスケジュールカレンダー

定期練習や大会、イベント日程をカレンダー形式でリアルタイムに更新。開催場所や持参物などの詳細も手軽に確認できます。

📲 オンライン参加予約＆体験申込

Web上から24時間いつでも体験参加やビジター利用の予約が可能。参加枠の管理もスムーズに行えます。

📸 コミュニティギャラリー＆活動発信

練習風景や試合のハイライト写真を掲載し、クラブの活気と温かいコミュニティの雰囲気を広く届けています。

https://fujimino.space/
🏆 ポータル概要： 地域住民やスポーツ愛好家が気軽に集い、健康的なライフスタイルを応援するアクティブな公式Webサイトです。

🏫 みんなのいえ 日本語教室 (Minna no Ie Japanese Class)

多文化共生を支える公的日本語教室ポータル＆オンライン無料予約システム

🔗 日本語教室を開く
Tailwind CSS 多言語エンジン (日本語 / やさしい日本語 / English) 予約システム直結 Google Maps API EmailJS お問い合わせ

一般社団法人 多文化共生推進プロジェクトが運営する無料日本語教室の公式ポータルサイトです。
ふじみ野市周辺に暮らす外国籍住民の方々が安心して学べるよう、温かみのあるデザインとともに「日本語」「やさしい日本語」「英語」の3言語切り替えに対応。弊社の予約システムとシームレスに直結し、スマートフォンから誰でも簡単にクラス予約が行えます。

📚 3つのレベル別クラス案内

日常会話を学ぶ「日曜クラス」、初心者向けの「水曜クラス」、お茶を飲みながら交流する「おしゃべりカフェ」の3つの講座情報をわかりやすく提供。

🌐 3言語リアルタイム切り替え

日本語・やさしい日本語（ふりがな・平易な表現）・英語を瞬時に切り替え可能。外国人利用者にとって極めて高いアクセシビリティを誇ります。

⚡ 予約システム直結（24h受付）

受講したいクラスを選択するだけで、オンライン予約システムへ直接遷移。待機時間なしで無料予約を完了できます。

🗺️ アクセス案内＆お問い合わせ

教室の所在地（埼玉県ふじみ野市亀久保）のGoogle Mapルート案内、よくある質問（FAQ）、EmailJSによる即時問い合わせフォームを完備。

https://jp.fujimino.space/
🤝 プロジェクト概要： 地域福祉・多文化共生をITで後押しする公共性の高いプラットフォーム。誰もが使いやすいユニバーサルデザインを採用しています。

🛒 ふじみ野 オンラインショップ (Fujimino EC Store)

商品検索・カート決済・在庫注文管理を備えたフル機能型ECプラットフォーム

🔗 ショップを開く
ECショッピングシステム 商品カタログ＆検索 ショッピングカート 注文・配送管理 顧客マイページ モバイル決済最適化

商品の閲覧からカート追加、チェックアウト・注文確定、発送管理までをスムーズに行える本格的なオンラインショッピング（EC）プラットフォームです。
スマートフォンでの購買体験を最重要視した直感的なUI設計を採用し、商品のカテゴリー別絞り込み検索、詳細スペックや画像表示、在庫連動、マイページでの注文履歴照会など、EC運営に求められる標準機能を網羅しています。

🛍️ 商品カタログ＆スマート検索

カテゴリー別分類、キーワード検索、人気・新着順ソートに対応。高精細な商品画像と分かりやすい商品説明で購買意欲を高めます。

🛒 カート機能＆スムーズ決済

数量の即時増減や小計・送料の自動計算に対応。離脱を防ぐストレスフリーでシンプルなチェックアウト導線を実現しています。

📦 注文・配送ステータス管理

受注後の注文ステータス（入金待ち・発送準備中・発送完了）をリアルタイム更新。顧客への自動通知メールと連動します。

👤 会員マイページ＆購入履歴

購入履歴の閲覧、お気に入り商品の保存、お届け先住所の登録・管理など、リピート購入を促すアカウント機能を完備。

https://shop.fujimino.space/
🛍️ プラットフォーム概要： 直感的で使いやすいモダンなECストアフロント。商品選定からチェックアウトまで軽快な操作性を提供します。
