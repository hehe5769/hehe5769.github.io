📅 预约管理系统 (Reservation & Matching System)

客户・业者・管理员三层协同架构，全流程工单智能匹配与履约管理平台

🔗 访问预约系统
Spring Boot PostgreSQL Spring Security Leaflet / Map API 自动邮件通知 响应式网页设计

本系统面向各类上门维修、保洁家政等生活服务场景量身打造，涵盖在线预约、多业者报价对比、工单分派、地图寻单到完工确认的全闭环管理。
顾客可直观发布与取消预约，对比最具性价比的报价单；业者可通过地图按距离筛选附近优质案件并即时制定报价；管理员则在全景大盘中实时掌控订单与资金流向。

👤 客户门户

提供极简预约流程，支持 24 小时在线下单、修改与取消。系统自动汇总多家业者报价单，一键横向比选最优性价比方案。

👷 业者地图寻单端

集成地理信息检索，通过地图直观展示案件距离与施工详情，支持在线快速出具报价单，并随时同步现场处理进度。

📊 管理员全景大盘

全盘动态可视化工单流转状态（新建、待确认、已确认、已完成），支持按时间/状态维度统计分析，并提供 CSV 报表导出。

🔒 多层安全权限鉴权

基于 Spring Security 实现严格的角色权限划分（RBAC），确保客户、业者、管理人员各自拥有独立清晰的数据隔离与安全防护。

👥 人事管理系统 (Fujimino HR System)

员工档案・考勤打卡・请休假审批全流程一体化数字 HR 解决方案

🔗 访问人事系统
现代 Web 前端 RESTful API 考勤工时计算引擎 多级审批工作流 角色权限体系 (RBAC) 云端高可用部署

专为企事业单位与组织团队打造的高效人事管理平台，旨在推动人事实务全流程无纸化与规范化。
支持员工电子档案管理、在线考勤打卡与工时统计，结合多级假期审批流与薪酬核算导出，大幅提升跨部门协作效率并降低人力管理成本。

🗂️ 员工全生命周期档案

涵盖基本资料、所属部门、职务职级、入职状态及履历变更，支持灵活的组织架构拓展与多维度人事检索。

⏱️ 考勤打卡与工时统计

支持在线打卡与排班出勤记录，自动核算常规工时、加班与缺勤情况，大幅减轻月末考勤汇总的工作负荷。

📝 假期申请与多级审批

年休假、事假、病假等各类假种在线填报，即时推送上级主管与人事部门审批，申请进度实时清晰可见。

📈 劳务数据分析与导出

提供月度出勤台账与请假明细 CSV 导出，无缝对接企业薪酬计算软件与财务流程。

https://hr.fujimino.space/
💻 系统概述： 基于云端的现代化 B 端 SaaS 管理台，提供直观的员工个人中心与 HR 运维后台，助力企业组织高效运转。

🏫 大家之家 日语教室 (Minna no Ie Japanese Class)

面向在日外籍人士的多文化共生公益日语教育门户与一键免登录预约平台

🔗 访问日语教室
Tailwind CSS 三语实时切换引擎 (日 / 简易日 / 英) 预约系统直连 Google Maps API 导航 EmailJS 表单集成

由一般社团法人 多文化共生推进项目主办的官方公益日语教室网站。
为方便ふじみ野市及周边外籍居民融入当地生活，网站采用温馨亲和的日式设计风格，原生支持「标准日语」「简单日语（带平假名助读）」与「英文」三语无缝切换，并与预约系统直接连通，手机即可一键免费预约课程。

📚 三阶递进式课程体系

详细介绍针对生活日常口语的「周日班」、零基础发音启蒙的「周三班」以及与本地居民喝茶畅聊的「交流咖啡厅」。

🌐 无障碍多语言即时切换

贴心提供适合初学者的“简单日语”模式，大幅降低外籍朋友的阅读门槛，体现高度的人文关怀。

点击相应班级即可直接调起在线预约系统，无繁琐流程，随时随地锁定学习席位。

嵌入真实校区地理定位与路线指引，配合常见问题解答（FAQ）与免后端邮件表单，咨询反馈迅速可靠。
